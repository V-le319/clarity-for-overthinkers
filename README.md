# Clarity — for overthinkers
 
A minimal web app that helps move from overthinking to action in four steps.

## Purpose
 
Built to practice TypeScript in a real project context, and to solve a personal problem — turning the spiral of overthinking into one concrete action with a time limit.
 
## What it does
 
1. **Write it out** — dump the thought living rent-free in your head
2. **Pick an action** — choose one small thing you can do right now
3. **Set a timer** — commit to 5, 15, or 30 minutes
4. **Do it** — a countdown holds you to it with pause and restart
 
## Tech stack
 
- React 17
- TypeScript
- Tailwind CSS
